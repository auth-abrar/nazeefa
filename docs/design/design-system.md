# Design System Tokens

## Semantic Color Tokens

CommerceOS utilizes CSS custom properties with an editorial luxury aesthetic:

- `--background`: Canvas backdrop
- `--foreground`: Primary text color
- `--surface`: Card and section surfaces
- `--surface-muted`: Inset surfaces, table headers, secondary blocks
- `--border`: Subdued hairline dividing lines
- `--accent`: High-contrast luxury accent
- `--success`, `--warning`, `--danger`, `--info`: Operational indicators

## Typography

- Display: Editorial Fashion Serif / Display Sans
- Interface: Modern Clean Sans (`Inter`)
- Bangla: Preloaded `SolaimanLipi` / `Kalpurush` for authentic Bengali rendering
